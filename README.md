# 守护深蓝 · Guardian of the Deep Blue

**深蓝智护——海洋生态 AI 研学站**：海洋科普、模拟实验、真实视觉模型照片识别、环保互动游戏与科普影片相结合的开源网站。

**在线体验**：[ocean.dnk.cc](https://ocean.dnk.cc/)　·　[新版预览](https://ocean.dnk.cc/preview/)　·　[完整作品说明](docs/作品说明.md)

## 主要能力

- 六种海洋生命图鉴及生态知识
- 三变量生态教学模拟、对照记录、数据图表及 CSV/研学报告导出
- 上传照片，通过已配置的服务端视觉模型 API 识别海洋生物
- 海洋环保挑战题与珊瑚礁救援小游戏
- 5 秒电影式片头与 218 秒《守护深蓝》科普影片

**重要边界**：生态指标是教学规则计算结果，非实测或准确预测；视觉模型可能误识别。网站依赖联网的识别服务提供真实图片识别能力。

## 本地开发与构建

```bash
npm ci
npm run dev
npm run build
```

要求 Node.js 20+。构建结果位于 `dist/`；根路径为经典版，`dist/preview/` 为新版。大型视频素材不在 Git 仓库，单独部署前需自行配置 `/videos/` 媒体路径。

## 目录

- `src/`：新版网站交互页面、模拟实验、任务、小游戏
- `classic/`：经典版前端
- `public/`：图片和轻量网页动画素材
- `backend/`：Python API 和服务单元示例
- `api/`：托管平台视觉识别接口
- `ops/`：部署脚本示例
- `docs/`：作品技术说明、可打印 PDF

## 视觉识别配置

设置服务端环境变量 `VISION_API_KEY`、`VISION_BASE_URL`、`VISION_MODEL`，确保模型支持图像输入。不要向 Git 提交真实密钥。前端只调用 `/api/identify`，由服务器转发模型请求。请为公开服务添加合理的限流、防滥用和隐私提示。
