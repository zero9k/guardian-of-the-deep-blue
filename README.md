# 守护深蓝 · Guardian of the Deep Blue

**深蓝智护——海洋生态 AI 研学站**

参赛学生：孔维泽｜哈尔滨市群力实验小学校｜指导教师：曹晓雨

这是作品**网站部分**的公开源码，包含两版前端、生态模拟实验室、海洋生物图鉴、AI 图片识别接口、守护任务、互动小游戏及后端服务示例。

在线作品：https://ocean.dnk.cc/

## 本地运行

```bash
npm ci
npm run dev
```

`npm run build` 生成 `dist/`，包含经典版首页和 `/preview/` 新版页面。

## 技术架构

- `src/`：新版前端及生态模拟、图鉴、小游戏、实验记录、图像识别交互。
- `classic/`：经典版前端，使用单独构建配置。
- `public/`：公开静态素材（不含大型影片）。
- `api/identify.js`：Vercel 兼容的视觉识别 API 入口。
- `backend/server.py`：Python 标准库实现的自托管 `/api/identify`、`/api/health`。
- `ops/`：自托管部署示例，需按自己的服务器环境调整。

实际视觉识别需要配置服务端 `VISION_API_KEY`、`VISION_BASE_URL`、`VISION_MODEL`。请勿提交真实凭据；`.env.example` 仅为示例。模型输出可能出错，应由用户核验。

生态实验室的各项指标为预设规则的**教学模拟**，不是实测环境数据或真实预测。

## 视频

5秒开场与218秒成片在正式网站独立存储，不包含在本源码仓库。页面引用 `/videos/` 文件，单独部署时可替换为自己的媒体地址或媒体素材。
