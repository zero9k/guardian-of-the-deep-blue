《深蓝智护——海洋生态 AI 研学站》作品说明

作品名称：守护深蓝——深蓝智护·海洋生态 AI 研学站
作品类型：海洋生态科普、教学模拟实验、AI 图片识别及互动研学网站
在线体验：https://ocean.dnk.cc/
公开源码：https://github.com/zero9k/guardian-of-the-deep-blue

一、背景与目标

海洋生物多样性、塑料污染与海水升温都值得关注。本作品希望把海洋知识、可重复操作的模拟实验、视觉模型识别、环保互动与科普短片放在同一个网站里，使访客从观看海洋、提出问题，逐步走向控制变量、记录数据、比较结果与思考保护行动。

二、主要功能

1. 海洋生命图鉴

介绍绿海龟、珊瑚、宽吻海豚、小丑鱼、鲸鲨、水母等海洋生命及相关生态知识。

2. 海洋生态模拟实验室

使用水温、污染指数和保护力度三个可调变量，通过预设教学规则计算珊瑚健康、鱼类活力、水体清澈度和综合指数等指标。支持保存对照条件、比较实验记录、查看趋势、导出 CSV 与研学报告。

重要说明：上述指标是用于探究变量关系的规则仿真数据，未经真实海洋观测校准，不能作为生态监测结果或科学预测。

3. AI 海洋生物图片识别

站内包含图鉴样例的标签匹配教学演示；另外，上传真实海洋生物照片后，可通过服务器 API 调用已配置的视觉模型进行图片识别和文字介绍。模型结果可能有误，使用者应主动核实。图片识别依赖网络和服务端配置；离线状态下不能保证可用。

4. 守护海洋任务与小游戏

环保知识题目涉及垃圾减量、珊瑚白化、废弃渔网及海洋动物保护。互动小游戏《深蓝守护者：珊瑚礁救援》让访客在模拟场景中清理垃圾、避开海洋生命，结合答题与即时反馈学习保护行动。

5. 作品影片与电影式开场

网站提供约 3 分 38 秒（218 秒）的《守护深蓝》科普影片，介绍海洋之美、生态问题及网站功能。网站使用 5 秒无声电影式开场，访客可以观看完整影片或跳过进入研学页面。完整影片提供适合网页快速播放的轻量版本；大体积媒体文件独立部署，不存放在 Git 源码库。

三、技术架构

  • 前端：HTML、CSS、JavaScript、Vite；classic/ 为经典站点，src/ 为新版站点。
  • 本地互动：图鉴、教学模拟、记录和小游戏主要在浏览器运行，无需注册账号。
  • 后端：backend/server.py 为 Python 标准库 API，支持健康检查和视觉识别转发；api/identify.js 提供另一种托管平台的接口实现。
  • 视觉模型：通过服务器环境变量配置模型供应商接口、模型名称和密钥，密钥不进入浏览器或公开仓库。
  • 媒体：HTML5 Video、H.264/AAC MP4、分段 HTTP 请求；大文件在网站服务器单独部署。
  • 发布：Git、GitHub、Nginx，相关部署示例见 ops/。

四、使用方法与演示路线

  1. 打开网站，观看或跳过短片开场。
  2. 查看海洋生命图鉴，选择感兴趣的物种。
  3. 进入生态模拟实验室，先保存基线条件，再仅改变一个变量，观察差异并记录结果。
  4. 上传有代表性的海洋生物照片，尝试 AI 识别并核对结果。
  5. 完成环保挑战或珊瑚礁救援小游戏，讨论哪些现实行为可以帮助保护海洋。

五、教学意义、真实性与边界

作品把海洋科普、控制变量、数据记录、AI 识别和环保行动结合起来，鼓励主动探索。但模型识别不保证准确，模拟实验也不等于真实科学研究；实际研究结论需要资料核验和真实观察支持。

开发过程使用 AI 编程工具和家长等成年人的技术协助，不应将软件生成的模拟结果或开发过程描述为学生独立完成的实地研究。作品面向学习与交流，持续改进。

六、隐私、开源与在线地址

在线视觉识别会把所选图片发送至网站服务器及配置的视觉模型服务，请勿上传包含隐私信息的照片。服务端密钥不随源码公开；网站不要求登录。参赛人员个人陈述与致谢不列入本公开技术说明。
