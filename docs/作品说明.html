《深蓝智护——海洋生态 AI 研学站》作品说明

参赛学生：孔维泽
所在学校：哈尔滨群力实验小学校
指导教师：曹晓雨

参赛方向：2026 哈尔滨市学生科技作品展示大赛，“做中学”实践类—信息技术应用类。

作品形式：浏览器交互式科学研学应用（B/S 静态网站，无需登录）。

一、作品背景与目标

海洋生物多样性和海洋污染、海水升温等问题与人类生活息息相关。作品希望通过便于操作的海洋生物图鉴、环境变量模拟和海洋保护互动任务，让使用者从“看到海洋”进一步发展到“提出问题、调整变量、比较结果”。

二、作品功能

1. 海洋生命图鉴

点击绿海龟、珊瑚、宽吻海豚、小丑鱼、鲸鲨和水母卡片，阅读其生活特点和常见生态威胁介绍。

2. 海洋生态模拟实验室（核心）

通过三个滑杆调整水温、污染指数和保护力度，界面实时计算四项模拟指标。点击“记录本次实验”保留本次参数及结果，可反复实验对比并导出 CSV 表格。适合按照“问题—猜想—控制变量—记录—比较—反思”的路径开展研学。

注意：所有指标是软件预设公式计算的模拟数据，不代表真实海域监测或准确预测。

可复现实验示例（待使用者亲自操作）：

  1. 记录初始条件：26°C、污染指数15%、保护力度60%。
  2. 仅调高水温至31°C，再记录一次，比较珊瑚健康模拟指标。
  3. 恢复初始条件，仅将污染指数提高至65%，再记录一次，比较水体清澈指标。
  4. 查看导出 CSV，讨论不同变量对模拟结果的影响和模型局限性。

3. AI 识别原理学习

从内置图鉴样例选择一种生物，观察样例标签如何与生物知识卡片关联；可以上传图片进行本地预览。图鉴样例是内置标签匹配的教学演示；如部署端已配置视觉模型 API，上传真实图片后可点击“在线 AI 识别”调用视觉服务，并显示判断依据、局限性与核验提示。未配置 API 时会明确报错，不捏造识别结论。

4. 海洋守护挑战

回答三道与塑料垃圾、珊瑚白化、废弃渔网有关的选择题，获得即时反馈，形成海洋环保意识。

三、技术说明

前端：HTML、CSS、JavaScript；构建：Vite。业务逻辑在浏览器本地运行。生态模拟等核心功能无需数据库、账号或外部 API。真实视觉识别需要可选的服务端 API 配置；离线运行时该功能不可用。支持现代电脑浏览器访问，可由静态服务器离线运行。源代码已按目录提供，主逻辑见 src/main.js。

四、创新与实用性

  • 将海洋科普知识与可控制变量的模拟实验相结合，不只提供被动阅读。
  • 实验条件与结果可以记录、导出，便于学生自行比较与讨论。
  • AI 教学板块显式披露系统能力边界，引导使用者核验人工智能输出。
  • 桌面与移动端适配，降低展示门槛。

五、操作路径（建议现场展示 3—5 分钟）

  1. 进入首页，点击“开始研学”。
  2. 在生态实验室调整污染指数，观察环境变化及四项指标。
  3. 点击“记录本次实验”，改变另一个变量后再次记录，导出 CSV。
  4. 展示图鉴与 AI 标签匹配教学演示，并解释其与真实视觉模型的区别。
  5. 完成一项海洋守护任务。

六、开发与实验真实性说明

由于实际交付时间紧，本版本由家长使用 AI 编程辅助完成。软件实验数据是可复现的规则仿真，而非学生实地考察或已经完成的个人实验。后续实际开展的学生探究过程应另行记录；不得以预写示例冒充本人完成的研究过程。
